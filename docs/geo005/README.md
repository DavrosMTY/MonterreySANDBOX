# GEO-005 / METRO-001 — base metropolitana

Base reproducible: GEO-004 `b201496`, PR #6; `development` aún no lo integra.
PR #6 depende de #5 y #4. Los seis PR existentes permanecen abiertos y no se
fusionan automáticamente. Se conserva UE5.6.1, GIS, artefactos y URLs anteriores.
Presupuesto de servicios US$0.

Primera etapa: delimitación oficial documentada, matriz de fuentes con cobertura,
GeoPackage maestro, índice estable de tiles y un sector real contiguo al piloto.
La disponibilidad de catálogo no equivale a terreno procesado o geometría validada.
Se auditan por separado precisión absoluta, coherencia interna y ejecución en motor.

Época objetivo propuesta: contemporánea 2026, corte de inventario 22/10/2026.
Cada observación conserva su período real o desconocido. Descargar OSM en 2026 no
certifica que cada objeto se haya observado en 2026; el MDT INEGI de 2007 no se
presentará como levantamiento actual. Fuentes temporales incompatibles se señalan.

La investigación inicial está en marcha. Los resultados ejecutados se incorporan
con recibos; esta nota no declara sectores o límites oficiales implementados aún.
